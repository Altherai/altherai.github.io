Real-World PC Test Bench

Creator Setup

The current ALTHERAI system is intentionally realistic: older but capable gaming hardware used to test modern PC games, recording impact and practical upgrade value.

Current PC

  • CPU: AMD Ryzen 5 3600.
  • GPU: NVIDIA GTX 1080 8GB.
  • RAM: 16GB.
  • OS: Windows 11.
  • Primary test resolution: 1920×1080.

Creator software

  • OBS for gameplay recording.
  • DaVinci Resolve and CapCut for editing workflows.
  • FFmpeg-based local processing where useful.
  • Real gameplay overlays/monitoring for FPS and resource usage.

Testing angle

  • Can current games still run well on GTX 1080-class hardware?
  • What changes when OBS recording is enabled?
  • Which settings are actually practical at 1080p?
  • How meaningful is a laptop/GPU/monitor/storage upgrade in real use?

Priority upgrade categories

  • Gaming laptops / compact PCs for desktop-replacement comparisons.
  • GPUs that enable visible generation-to-generation comparisons.
  • Gaming monitors for 1080p/1440p and refresh-rate tests.
  • SSD/storage for recording, editing and archive workflows.
  • Other hardware only when it supports a concrete, measurable video idea.

Current baseline

The GTX 1080 desktop is the reference point. New hardware can be compared against the same games, OBS workflow and normal-player conditions instead of being reviewed in isolation.

What we do not fake

No invented averages, no unsupported smoothness claims and no forced positive verdicts. If a setting, game or product performs poorly, that result is still useful content.

Example planned tests

  • GTX 1080 desktop vs modern gaming laptop while OBS records.
  • 1080p vs 1440p practical gaming on current live-service titles.
  • OBS OFF vs OBS ON launch-day performance tests.
  • SSD recording/edit/archive workflow with real project files.
